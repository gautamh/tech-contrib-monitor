# Gemini Usage Guidelines

This file provides guidelines for using Gemini to assist with development in this repository.

## Progress Log

A progress log is maintained in `progress_log.md`. This file should be referenced for context on previous work and should be updated regularly to reflect the latest progress. **No sensitive information should be outputted to the `progress_log.md` file.**

## Documentation

When making changes to the codebase, you should also update the `DEV_NOTES.md` file where appropriate to reflect architectural changes, new features, or significant design decisions.
